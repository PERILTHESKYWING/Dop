# /two-ways

Pick a direction first, polish second. Polishing one direction for many rounds wastes effort when the direction itself is wrong.

1. From the ask, the reference images and the /taste rules, write two directions that differ in something the user will notice at a glance (layout, mood, material, density, motion), each in one line. Not two shades of the same idea.
2. Build both to the same rough level: enough to judge the direction, not finished. Same content, same screen sizes.
3. Screenshot both with the same frames (see design-shots if saved) and put them side by side, labelled A and B, with one line each on what it is going for and its main trade-off.
4. Recommend one, with the reason, and ask the user to pick (A, B, or "mix: X from A, Y from B"). Use a decision card if the tool exists.
5. Keep working on the recommended one while waiting; switch if the user picks the other.
6. After the pick, delete the losing version's code so it doesn't linger.

Skip it for small fixes to an existing design or when the user already chose a direction.
